# Wordclock

Заставка для macOS, которая показывает текущее время прописью: не «21:14», а
«Четырнадцать минут десятого». Формулировки для каждой минуты берутся из
`Russia.json` и `English.json`, для одной минуты их бывает до одиннадцати.

## Об идее

Проект сделан по мотивам часов **Verbarius**, разработанных в
[Студии Артемия Лебедева](https://www.artlebedev.ru). Это любительский пример
реализации самой идеи «часов, называющих время словами» — учебный код,
написанный с нуля, без коммерческого использования.

Проект никак не связан со Студией Артемия Лебедева и не является её продуктом.
Название Verbarius, оригинальный дизайн часов и их прошивка принадлежат студии.
Если вы правообладатель и считаете, что что-то в репозитории нарушает ваши
права, — напишите, материал будет удалён.

## Установка

1. Открыть `WordclockScreenSaver.xcodeproj` в Xcode, собрать (⌘B).
2. `Products → WordclockScreenSaver.saver → Show in Finder`, двойной клик по
   файлу либо скопировать его в `~/Library/Screen Savers/`.
3. `Системные настройки → Заставка → Wordclock`. Кнопка «Параметры» открывает
   выбор языка, разнообразия формулировок, смещения текста и размера шрифта.

Требуется macOS 13 или новее. Подробности реализации — в
[`WordclockScreenSaver/README.md`](WordclockScreenSaver/README.md).
